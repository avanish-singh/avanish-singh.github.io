1 · The device and the data

A silicon film between two gates, and Poisson's equation across it

The structure is a symmetric double-gate MOS stack: a silicon body of thickness Tsi between two 2 nm gate dielectrics, each covered by a gate held at the same voltage Vg. Both sides are identical, so every profile is a mirror image about the body center.

For each device, TCAD solved Poisson's equation through the stack:

d/dy ( ε · dψ/dy ) = −ρ(y)

Three rules shape every curve on this page:

  • Dielectric: straight lines. There is no charge in the oxide, so ψ changes linearly.
  • Interface: a kink. The displacement ε·dψ/dy is continuous, so the slope jumps where ε changes.
  • Silicon: curvature is charge. ψ″ = −ρ/εSi. Bend up means negative charge, bend down means positive.

OFF state: 0.6 V. Inside the silicon the curvature is 1.55 × 10⁻⁴ V/nm², exactly constant at 0.6 V and within about 10% at 0.8 V. Through Poisson's equation that is a fixed negative charge of 1.0 × 10¹⁷ cm⁻³: a p-type body that is fully depleted, holding ionized acceptors and no mobile carriers, so no channel conducts. The potential sags into a parabola whose depth grows with Tsi², from 0.17 mV in a 3 nm body to 13 mV in a 26 nm one.

ON state: 1.2 V. The gate now pulls in an inversion layer of electrons, the conducting channel. The swing between surface and center grows to tens and then hundreds of millivolts, and the curvature stops being constant. At 1.0 V inversion is already forming; 0.8 V is still depleted.

The dataset is 116 thicknesses (3.0 to 26.0 nm in 0.2 nm steps) × 4 gate voltages = 464 profiles, sampled every 0.05 nm. The atlas shows all of them at once.

2 · Each file becomes a graph

One mesh point is one node; neighbors are joined by two directed edges

graph_builder.py turns one text file into one PyTorch Geometric graph:

  • File name → total thickness. Potential_1.98e-08.txt is 19.8 nm, so Tsi = 19.8 − 2 × 2 = 15.8 nm.
  • Folder name → gate voltage. Vg_1.2 → 1.2 V.
  • Each line → one node at y = (i + ½) × 0.05 nm. The value on that line is the node's target, data.y.
  • Neighbors → edges i→i+1 and i+1→i, so N nodes give 2(N−1) directed edges.

The potential is never an input. A node is described by 16 numbers: where it is, which material it sits in, how far it is from each gate and interface, and which device it belongs to. Edges carry 3 numbers: the signed spacing (so a node can tell its upper neighbor from its lower one), the absolute spacing, and a flag for the one edge that crosses each dielectric/silicon interface.

Four of the 16 features are identical at every node of a graph: Tsi, Tox, total thickness and Vg (highlighted in the table). They are how a node deep inside the silicon knows which device it is in. Section 3 shows why that matters more than the edges do.

No structured grid needed. Every device is its own graph, with as many nodes as its mesh has: 140 for the thinnest body, 600 for the thickest. Node features are physical positions and distances, and each edge carries its own spacing, so nothing ties the network to a fixed grid. The Mesh switch in the simulator runs the same trained network on graded and randomly placed nodes; section 6 has the numbers.

Message

For each incoming edge j→i, an MLP reads [hᵢ, hⱼ, eᵢⱼ]: 96 + 96 + 3 = 195 numbers. It returns a 96-number message. Because eᵢⱼ holds the signed spacing, messages from above and below are distinguishable.

Aggregate

The incoming messages are averaged. Interior nodes have two (one from each neighbor); the first and last nodes, which touch the gates, have one.

Update

A second MLP reads [hᵢ, mean message]. Its output is added back to hᵢ (a residual connection) and LayerNorm rescales the sum. The result is the node's state for the next layer.

How far does information travel?

Each layer moves information one edge, 0.05 nm. Eight layers reach 8 nodes, or 0.40 nm, in each direction. For the device in the simulator, the body center is — from either gate.

So message passing alone cannot tell the center of the silicon what the gates are doing, yet the model predicts the center potential well. The global information comes from the node features: every node is handed its normalized position, its distances to both gates and both interfaces, and the device's Tsi and Vg. In practice the network behaves like a per-node regression on those coordinates, with the eight layers adding local smoothing and helping at the interface kinks. It is also why the network carries over to meshes it never trained on.

The Play the layers button in the simulator shows this. It applies the decoder to the hidden state after each layer. At layer 0 every node reads out close to the dataset mean; the profile takes shape over the next layers, mostly from the features rather than from neighbors far away.

4 · The loss

Match the value, the slope and the curvature

losses.py trains with a Sobolev loss. Each term is a SmoothL1 penalty, computed on normalized potential (ψ − μ)/σ and normalized position y/T:

L = ℓ(ψ̂, ψ) + λg·ℓ(ψ̂′, ψ′) + λc·ℓ(ψ̂″, ψ″)

Optuna set λg = 0.0555 and λc = 0.00104. Derivatives are finite differences along each chain, never across two graphs in a batch.

In device terms the three targets are the potential, the electric field (E = −dψ/dy) and, through Poisson's equation, the charge density (ρ = −εSi·ψ″). The charts follow the simulator, in physical units.

  • Field. Flat in each dielectric, a jump at each interface, then a smooth decay to zero at the body center, where symmetry forces it.
  • Charge. At 0.6 V the TCAD curve is a flat −1.0 × 10¹⁷ cm⁻³ (the depleted acceptors). At 1.2 V in thin bodies the charge peaks at the center rather than at the interfaces, the signature of volume inversion. The 1.0 V and 1.2 V files store six decimals, which shows up as speckle in this chart.

MAPE is deliberately left out of training because ψ crosses zero; it is reported only for points where |ψ| ≥ 5 mV.

5 · Training

A 30-trial Optuna search, then 656 epochs with the winner

train_full.py ran two stages on the workstation. Optuna's TPE sampler tried 30 configurations for up to 50 epochs each and kept the one with the lowest validation loss, trial 11. Full training then used those settings: Adam at 8.7 × 10⁻⁴, batch size 8, weight decay 9.3 × 10⁻⁴.

ReduceLROnPlateau multiplied the learning rate by 0.63 whenever validation loss stalled for 16 epochs. The best validation loss came at epoch 556, which is the checkpoint running on this page. Early stopping ended the run at epoch 656, after 100 epochs without improvement, with the learning rate at its floor of 10⁻⁶.

The components tell different stories. The value loss falls about 4,400× (0.47 → 0.00011) and the slope loss about 260×. The curvature loss falls only 25× and levels off near 1.6 (train) and 2.0 (validation).

Across the Optuna trials, every one of the six best runs sits at the very bottom of the λc search range (0.001 to 0.05). The search was asking for less curvature weight than it was allowed to give.

6 · How well it does

About 1.5 mV at every bias and thickness, and on meshes it never saw

Train, validation and test thicknesses all land at about 1.46 mV mean absolute error. There is no gap between thicknesses the network trained on and ones it never saw, so it interpolates in Tsi as well as it fits.

Relative to how much each profile varies, the picture depends on the bias. In the ON state (1.2 V) the error is under 1% of the profile's range (median 0.6%). In the OFF state (0.6 V) the whole profile varies by only 1 to 20 mV, so the same millivolt error is a much larger share of it: 24% of the range at the median. Capturing that low-bias shape more precisely is the next step.

Both are test thicknesses. Use “Zoom to profile” to see the shape and “Fixed axis” to see it against the full potential range.

Quick reference

Terms used on this page

TCADTechnology CAD: a numerical device simulator that solves Poisson's equation (and carrier transport) on a mesh. Here it supplied the ground truth.
DepletionMobile holes pushed out of a p-type body by the gate field, leaving fixed negative acceptor ions. Gives constant curvature.
InversionEnough gate voltage to pull a layer of electrons into a p-type body. The channel of a MOSFET.
Volume inversionIn very thin bodies, the inversion electrons spread through the whole film instead of sitting at the two surfaces.
OFF / ON stateHere 0.6 V, where the body is depleted and no channel conducts, and 1.2 V, where an inversion layer forms the channel.
Unstructured meshNodes placed wherever the geometry needs them, at uneven spacing, instead of on a regular grid. A graph network takes either, because each edge carries its own spacing.
Message passingEach layer, every node combines its own state with messages computed from its neighbors' states and the edge between them.
Receptive fieldThe set of nodes that can influence a node's output. For a chain and k layers it is k nodes on each side.
Sobolev lossA loss that penalizes errors in derivatives as well as values, so the shape is matched, not only the level.
LayerNormRescales each node's 96 numbers to zero mean and unit variance, then applies a learned scale and shift. Keeps deep stacks stable.
Split by thicknessAll four voltages of a Tsi go to the same split, so held-out sets test genuinely unseen devices.
